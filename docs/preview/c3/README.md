# Preview C3 — trang phục phương Đông LPC

Ảnh được ghép từ các sheet `LPC_PARTS` sau khi đóng gói bằng `tools/assets/lpc-parts.mjs`.

- `c3-directions.png`: 4 hàng là Sử Lai Khắc nam/nữ và Vũ Hồn Điện nam/nữ; 4 cột là nam, đông, bắc, tây.
- `c3-states.png`: cùng 4 bộ, lần lượt đứng, đi, chém, niệm phép.

Mỗi sheet giữ khung LPC 64×64, gốc (32,58), bốn hướng chạy và các dải walk / slash / spellcast / hurt theo `LPC_SHEET`.
